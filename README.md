# AI Journal Companion Data Structures

A reusable Kotlin/JVM library containing custom data structures and sorting algorithms used by the AI Journal Companion Android application.

## Included Components

- `BinaryTreeObject` — groups and searches objects by key
- `BinarySearchTree` — standard binary search tree
- `HashMapObject` — groups objects using key-based lookup
- `DoublyLinkedList` — linked-list storage and sequential searching
- `SortAlgorithms`:
  - Bubble Sort
  - Insertion Sort
  - Selection Sort

## Requirements

- JDK 21
- Gradle Wrapper included
